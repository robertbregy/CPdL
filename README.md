# CPdL · Simulatore scala contributiva — prototipo v0.4 v0.4

Prototipo statico per GitHub Pages. Nessuna autenticazione, database o backend: i calcoli avvengono localmente nel browser.

## Pubblicazione su GitHub Pages
1. Sovrascrivi nella root del repository `index.html`, `assets/` e `README.md` con i file di questa versione.
2. Mantieni GitHub Pages su **Deploy from a branch**, branch `main`, cartella `/(root)`.
3. Attendi il deploy.

## Novità grafiche v0.4
- identità visiva più vicina a un servizio previdenziale istituzionale;
- hero più editoriale e meno "landing page generica";
- percorso in 4 passaggi sempre leggibile;
- primo input trattato come vero punto d'ingresso del servizio;
- confronto delle scale più pulito e più leggibile;
- riepilogo decisionale portato dentro il flusso del simulatore;
- gerarchia tipografica e spaziature riviste;
- stato selezionato, stato corrente e variazioni positive/negative più chiari;
- migliore resa mobile.
